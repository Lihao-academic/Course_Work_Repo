* **DataVisualizationProject**
  * The project structure is somewhat disorganized—with data uploaded alongside the code—due to my initial unfamiliarity with project structuring.

* **Social Issues in Information Society**
  * This project discusses the domestic and international political impacts of ICT and AI by integrating relevant concepts; it consists solely of a paper and a presentation (PPT), with no accompanying data or code.
* **Deep Learning Project - Classifier on HMDB51**
  * This project utilizes a pre-trained model on the HMDB51 dataset to train a CNN+RNN architecture for video classification; further details are provided within the project files.
* **Data Science Lab**
  * This project investigates financial literacy in Italy, executing the full process from conceptualization to operationalization—quantifying abstract concepts into comparable metrics—followed by analysis and discussion.
* **Financial Market Analytics**
  * This project uses historical S&P 500 data to calculate stock correlations and implement a pairs trading strategy; while the results were not ideal, the strategy successfully achieved risk diversification.
